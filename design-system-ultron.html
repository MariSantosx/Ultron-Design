02

Tipografia

Uma única família, PP Neue Montreal (Pangram Pangram), em três pesos. Títulos enormes com entrelinha 0.9 e tracking negativo; rótulos pequenos sempre em caixa alta, semibold, com tracking de 0.025em. O html do site usa font-size: .8333vw, então 1rem = 16px numa tela de 1920px e tudo escala junto.

05

Efeitos

O site não usa nenhuma box-shadow. A profundidade vem de vidro fosco (blur de 20px sobre gradiente preto translúcido), de fotos apagadas em cinza que acendem quando ficam ativas e da própria cena 3D. O glow laranja é uma sugestão para destacar CTAs em fundo preto.

06

Movimento

Dois grupos de curvas. As do CSS cuidam de hovers e cores. As do GSAP (JavaScript) cuidam de tudo que entra, sai ou gira; a assinatura do site é expo.out: arranque rápido e pouso bem longo. Clique em um card para ver a curva.

Animações

Todas as animações em JavaScript do site, com os mesmos valores do código original (GSAP 3 + ScrollTrigger). Elas já estão rodando nesta página: os títulos entram em linhas, o logo encolhe quando você rola, o menu troca as letras no hover. Use "Repetir" para ver de novo.

01 · Loader de entrada

Tela preta com 4 quadrados girando 90° (quad.inOut, 1s). Quando a cena carrega, "LOADING" sobe girando 5° e cada linha do título sobe girando 2°, as duas em 2s com expo.out, 0.1s uma depois da outra.

heading: yPercent -120, rotate 2, stagger .1, expo.out, 2s

08 · Rolagem suave

O site move a página sozinho: a cada quadro o scroll anda 7,5% da distância até onde a roda do mouse mandou. Dá o deslizar macio. Desligue para comparar.

current += (target − current) × 0.075

gsap.from(lines, {            // cada linha fica dentro de um wrapper com overflow:hidden
  y: "120%", rotate: 7, transformOrigin: "0 0",
  duration: .8, ease: "power3.out",
  stagger: { each: .1, ease: "power1.in" },
  scrollTrigger: { trigger: el, start: "top bottom" }
});

// Blocos girando para dentro
gsap.from(el, { yPercent: 100, autoAlpha: 0, rotate: 14, ease: "expo.out", duration: 1 });

// Saída do loader
gsap.timeline()
  .to(loadingText, { yPercent: -110, rotate: 5, ease: "expo.out", duration: 2 }, 0)
  .to(headingLines, { yPercent: -120, rotate: 2, ease: "expo.out", duration: 2, stagger: .1 }, 0);

// Logo do header ao rolar
gsap.to(logoLetters, { y: "-100%", duration: 1, ease: "expo.out", stagger: .05 });
gsap.to(headerBg, { scaleY: 1, duration: 1, ease: "expo.out" });

// Hover do menu: letra sobe e a cópia (text-shadow) assume o lugar
gsap.timeline({ paused: true })
  .set(chars, { textShadow: "0 1.4em" })
  .to(chars, { yPercent: -100, duration: .5, ease: "power1.out", stagger: .035 })
  .set(chars, { yPercent: 0, textShadow: "none" });

// Parallax
gsap.from(el, { y: "-5vw", scrollTrigger: { trigger: el, scrub: .5, start: "top bottom" } });

// Rolagem suave
current += (target - current) * 0.075; window.scrollTo(0, current);

09

Cena 3D

O cérebro é uma cena three.js com 10.000 pirâmides (7.000 no celular) desenhadas de uma vez. As posições vêm de uma textura (pos-33.exr) com 4 formações; as cores (cd-33.png) e os tamanhos (sc-33.png) vêm de outras duas. Conforme a página rola, um único número, o progresso de seção, controla rotação, posição, explosão e qual formação aparece. O mouse empurra as pirâmides próximas e gira a câmera de leve. Role para ver as 5 fases.

Fase 1 · progresso 1 → 2.2

Dispersão

O cérebro desliza para a direita e as pirâmides se soltam. Cada uma multiplica a própria posição por um fator de 1 a 6, de baixo para cima. u_explode 0 → 1

Fase 2 · progresso 2.7 → 3

Lâmpada

Tudo se recolhe numa lâmpada, montada da esquerda para a direita, enquanto o objeto gira 90° e inclina 0.49 rad. u_progress 0 → 1

Fase 3 · progresso 3.3 → 3.5

Esfera

A lâmpada vira uma esfera, que vai para a direita, cresce um pouco e inclina para o outro lado. u_progress 1 → 2

Fase 4 · progresso 4.5 → 5

Nova dispersão

A esfera explode de novo enquanto gira 225° para trás. u_explode 0 → 1

Fase 5 · progresso 5.7 → 6

Logo

As pirâmides se juntam no "D" do logo Dala, que sobe, diminui e gira de frente. u_progress 2 → 3
